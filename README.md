🚀 Skill Gap Analyzer

Analyze Your Skills. Identify Your Gaps. Build Your Future.

Skill Gap Analyzer is a project designed to help users understand their current skills and identify areas where they can improve to achieve their career goals.

📌 Project Overview

The Skill Gap Analyzer aims to help users identify skill gaps and understand which skills they need to develop for their desired career path.

⚙️ Installation

1. Clone the repository:

git clone https://github.com/akshattnakle/brahmcode.git

2. Open the project folder:

cd brahmcode

3. Open the project in VS Code.

▶️ How to Run

The exact backend run command depends on the Python framework and dependencies used in "Backend/app.py".

Open the frontend using your development environment and configure the backend connection as required.
